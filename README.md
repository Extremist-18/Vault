# Vault

Vault is a blockchain based expense tracking platform designed to provide security, transparency, and trust in personal finance management.
In today’s digital environment, users often hesitate to share financial data online due to fear of breaches or leaks.
Vault addresses this challenge by leveraging blockchain immutability and end-to-end encryption, ensuring that all expense data is both tamper-proof and confidential.

-----------------------------------------------------------------------------------------------------------------

# Key Features

Smart Contract-Powered Ledger: All transactions and expense records are securely stored on the blockchain.

Data Privacy and Encryption: Sensitive information is encrypted before being transmitted or stored, assuring users of complete data confidentiality.

User Trust & Transparency: Every entry is cryptographically verifiable, eliminating the need for third-party validation.

Modern Frontend: A responsive React interface that allows seamless interaction with deployed smart contracts.

Wallet Integration: Direct connectivity with MetaMask for secure user authentication and contract interaction.

Local Blockchain Testing: Integrated with Hardhat for easy local deployment and testing.
